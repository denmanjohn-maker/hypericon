# Making a theme

A theme is a folder containing a manifest and one PNG of **artwork** per folder type. A theme does not draw the folder and does not choose its colour: HyperIcon draws a plain folder in the colour of each folder's Finder tag and puts your artwork on top. The bundled themes draw one object from their world (a pumpkin, a gift tag, a cassette) carrying a clear symbol for what is inside.

```
my-theme/
  theme.json
  preview.png      (optional, shown in the menu; 3:2 works best)
  folder.png       (required)
  git.png
  documents.png
  ...
```

Put the folder in `~/Library/Application Support/HyperIcon/Themes/` (Settings → **Open My Themes Folder**), then choose **Rescan Folders** from the menu. A theme with the same `id` as a bundled one replaces it.

## theme.json

```json
{
  "id": "my-theme",
  "name": "My Theme",
  "group": "Custom",
  "description": "One line shown as a tooltip."
}
```

`id` and `name` are required. `id` should match the folder name.

## Icons

- PNG with transparency, square, 512×512 (the same canvas as the folder it is drawn on).
- Draw **only the artwork**, with everything else transparent. HyperIcon's folder fills roughly x 40–472, y 118–436; its front face, where artwork belongs, is roughly x 40–472, y 178–436. The bundled themes keep their object within about x 130–382, y 190–420.
- Keep the outer 40 px empty. `tools/check_themes.py` rejects artwork that reaches the edge, because that usually means a background or a folder was drawn in.
- Do not pick a folder colour; the user's tag colour is drawn underneath. Make sure the artwork reads on all seven colours (blue, gray, green, purple, yellow, red, orange). A drop shadow or outline on the object helps.
- Only `folder.png` is required. Any type you leave out falls back to it.

| File | Used for |
| --- | --- |
| `folder` | Anything not matched below |
| `git` | Git repositories |
| `xcode`, `node`, `python`, `rust`, `go`, `java`, `dotnet` | Projects in that language or toolchain |
| `docker`, `kubernetes`, `terraform`, `ci` | Container, Helm/Kustomize, Terraform and pipeline folders |
| `documents`, `spreadsheets`, `presentations`, `pdf` | Office files |
| `images`, `music`, `video` | Media |
| `code`, `archives`, `fonts`, `books`, `design`, `data`, `web` | Other majority types |

The full list is also in [`Themes/categories.json`](../Themes/categories.json).

## Adding a bundled theme

Bundled themes are generated, not drawn by hand. In [`tools/icongen/gen.py`](../tools/icongen/gen.py):

1. Write a function that returns the SVG for one category by calling `art(...)` with your object and how the symbol sits on it. The existing themes are short examples. The plain folders in `Themes/_base/` are generated by the same script from `BASE_COLORS`.
2. Add an entry to `THEMES`.
3. Rebuild and check:

```bash
python3 tools/icongen/gen.py my-theme
```

```bash
python3 tools/check_themes.py
```

```bash
python3 tools/site/build.py
```

Glyphs are shared by every theme and live in [`tools/icongen/glyphs.py`](../tools/icongen/glyphs.py). Keep new artwork original: no vendor logos and no copies of another operating system's icons.
